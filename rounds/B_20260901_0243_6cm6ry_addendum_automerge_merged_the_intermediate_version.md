## บทเรียนที่ต้องบันทึก ไม่ใช่แค่แก้

1. **draft ไม่ใช่เครื่องกั้น** reaper ปลดให้เองที่ 45 นาทีตามที่คู่มือเขียนไว้
2. **การถอด marker ไม่ใช่เครื่องกั้น ถ้ายังพิมพ์สตริงนั้นในเนื้อความ** เครื่องมือ match สตริง
   ไม่ match เจตนา ทางเดียวที่กันได้จริงคือไม่มีสตริงนั้นอยู่ใน body เลย
3. ⇒ **การรีวิวต้องเสร็จก่อนใส่ marker** ไม่ใช่หลัง ลำดับ "push -> body+marker -> ปลด draft"
   ปลอดภัยเฉพาะเมื่อของที่ push ผ่านการหักล้างมาแล้ว
4. รอบนี้แก้สามรอบ แต่ละรอบแก้ข้อผิดของรอบก่อนแล้วสร้างข้อผิดชนิดเดียวกันขึ้นใหม่หนึ่งข้อ
   (ราคาที่รับช่วงมาโดยไม่วัดเองที่ HEAD ปรากฏซ้ำสองครั้ง · tautology ถูกย้ายขึ้นไปอีกชั้นแทนที่จะถูกลบ)
   สิ่งที่หยุดวงจรได้คือการ **หดข้ออ้างลง** ไม่ใช่การวิเคราะห์เพิ่ม
